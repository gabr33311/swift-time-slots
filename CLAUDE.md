# Regras do projeto

Aplicam-se a todos os pedidos.

1. **Experiência acima de tudo:** o objetivo é a melhor experiência possível, simples e intuitiva, tanto para o cliente que faz a marcação como para o admin.
2. **Cores:** tema preto, branco e tons de cinzento. Dourado e prateado só em elementos premium, com muita moderação e poucas vezes.
3. **Animações:** subtis, que transmitam robustez. Nunca exageradas.
4. **Mobile e PC:** tudo tem de funcionar bem nos dois.
5. **Git:** nunca fazer push nem alterar o ramo `main` sem pedido explícito.
6. **Respostas:** curtas, em português de Portugal.
